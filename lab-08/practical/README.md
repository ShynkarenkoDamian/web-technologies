# Практична частина лабораторної №8

Відкрийте `index.html`, щоб перейти до завдань 3–6.

- `task-3-gallery` — адаптивна галерея фотографій вовків.
- `task-4-cards` — адаптивні картки з наданими фото 1 і 2.
- `task-5-layout` — адаптивний макет зроблено двома способами: рядками й колонками та іменованими областями.
- `task-6-tree` — сітка з 28 блоків; номери створюються CSS-лічильником, блоки мають однотонну заливку.

Фото вовків збережені локально в `assets/wolves`. Їх автори та ліцензії вказані у `assets/wolves/credits.txt`. Надані фото лежать у `assets/personal`.
