# Лабораторна робота №8 — CSS Grid Layout

**Тема:** основи CSS Grid Layout.  
**Мета:** навчитися створювати двовимірні та адаптивні сітки за допомогою CSS Grid.

## Як відкрити роботу

Відкрийте `practical/index.html` у браузері. Це меню веде до практичних сторінок 3–6. HTML-розмітка і стилі кожної сторінки лежать поруч у відповідній папці.

## Де лежать завдання

### Завдання 2 — CSS Grid курс

У `css-grid-master` зібрані приклади уроків від `02 - Starter Files and Tooling Setup` до `25 - Full Bleed Blog Layout`. Файли `*-START` — початкові вправи, `*-FINISHED` — приклади з готовим рішенням. Код уроку відкривається у браузері як HTML-файл, а стилі — у редакторі.

**Перед здачею перевірте:** умова також просить скриншот прогресу на CSS Grid курсі. У цій папці я не знайшов такого скриншота. Якщо його ще немає у вашому репозиторії, збережіть його з курсу в `css-grid-master`.

### Завдання 3 — галерея фотографій

Файли: `practical/task-3-gallery/index.html` і `practical/task-3-gallery/style.css`.

Галерея має десять зображень вовків. На широкому екрані сітка має п'ять колонок; центральне фото займає кілька колонок і рядків. На ширинах до 768 px і 576 px кількість колонок і розташування змінюються. `object-fit: cover` заповнює комірку фотографією без спотворення пропорцій.

**Що показати:** клас `.gallery`, розміщення `.tile-main` через `grid-column` і `grid-row`, два медіазапити.

### Завдання 4 — картки

Файли: `practical/task-4-cards/index.html` і `practical/task-4-cards/style.css`.

Сітка складається з великої картки та п'яти менших. Велика картка займає дві колонки й два рядки через `grid-column: span 2` та `grid-row: span 2`. Усередині картки фото й текст розкладені окремою сіткою. Текстова частина має `overflow: auto`, а кнопки ведуть на сторінку про вовка. Зараз у картках використані надані фото 1 і 2. Для адаптивності є медіазапити до 768 px і 576 px.

**Що показати:** `.cards`, `.card-feature`, внутрішні рядки `.card`, прокручування тексту в `.card-body`.

### Завдання 5 — адаптивний макет двома способами

Файли: `practical/task-5-layout/index.html` і `practical/task-5-layout/style.css`.

На сторінці розміщено два однакових за змістом макети:

1. `.layout-rows` — блоки ставляться явно через `grid-column` і `grid-row`.
2. `.layout-areas` — блоки отримують назви через `grid-area`, а форма сітки описується у `grid-template-areas`.

Базовий варіант розташовує елементи в одну колонку. Медіазапити від 576 px і 768 px перебудовують макет для планшета та комп'ютера.

**Що показати:** два блоки HTML у `index.html` і відповідні правила `.layout-rows` та `.layout-areas` у CSS.

### Завдання 6 — деревоподібна структура блоків

Файли: `practical/task-6-tree/index.html` і `practical/task-6-tree/style.css`.

Сторінка містить 28 блоків у шести рядах: 1, 2, 3, 4, 6 і 12 комірок. Номери не записані в HTML: лічильник скидається правилом `counter-reset`, збільшується в `::before` через `counter-increment`, а показується через `content`. Блоки мають однотонну жовту заливку.

**Що показати:** ряди `.level-*` у HTML та CSS-лічильник `.block::before`.

## Коротка шпаргалка для захисту

- **Що таке CSS Grid?** Система двовимірної сітки: вона керує і колонками, і рядками.
- **Чим Grid відрізняється від Flexbox?** Grid зручний для розкладки у двох вимірах; Flexbox зазвичай розкладає елементи в одному напрямку — у рядок або колонку.
- **Що робить `fr`?** Ділить вільний простір між колонками або рядками.
- **Для чого `gap`?** Задає проміжок між комірками сітки.
- **Як блок займає кілька комірок?** Через `grid-column` і `grid-row`, як велика картка у завданні 4.
- **Навіщо `grid-template-areas`?** Дозволяє задати макет іменованими областями, схематично показавши їх розташування.
- **Як працюють номери у завданні 6?** CSS-лічильник автоматично рахує блоки та виводить номер псевдоелементом `::before`.
- **Навіщо `overflow: auto` у картці?** Якщо тексту більше, ніж доступного місця, його можна прокрутити всередині картки.
