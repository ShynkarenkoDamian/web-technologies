Навігаційні панелі

При наведенні або фокусі відкриваються вкладені списки меню. Горизонтальна панель закріплена зверху, а внутрішня панель розділів прилипає під час прокручування.

Огляд

Приклад сторінки демонструє фіксоване верхнє меню, липку панель розділів і вертикальну панель на всю висоту вікна.

Послуги

Підменю відкриваються наведенням миші або клавіатурним фокусом на пункті навігації.

HTML

Вкладені марковані списки задають рівні навігації та посилання між розділами.

CSS

Позиціонування використовує fixed для верхньої панелі, sticky для панелі розділів та absolute для випадних списків.

Про курс

Поточний пункт позначено окремим стилем, а стан hover змінює кольори елементів навігації.

Матеріали

Для першого рівня обох навігацій використано Google Fonts Icons.

Контакти

Останній пункт горизонтального меню вирівнюється праворуч за допомогою float.
